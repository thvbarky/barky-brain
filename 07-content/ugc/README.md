# UGC — User Generated Content Barky

---

## Pourquoi l'UGC est critique pour Barky

Dans le marché des compléments animaux, la preuve sociale est le facteur numéro 1 de conversion. Un vrai owner qui montre son chien vaut 10x une pub professionnelle.

---

## Comment obtenir de l'UGC

### 1. Clients organiques
- Séquence email J+7 : demander photo + review
- Offrir une récompense (réduction prochaine commande, cadeau)
- Reposter systématiquement avec permission

### 2. Créateurs micro-influenceurs
- Profil cible : compte chien, 5k-50k abonnés, FR
- Deal : produit offert contre contenu
- Brief à fournir : voir template ci-dessous

### 3. Campagne "Montre ton chien Barky"
- Challenge sur TikTok et Instagram
- Hashtag dédié (#MonChienBarky ou similaire)

---

## Brief UGC type

Objectif du contenu : [ex: montrer le produit en utilisation quotidienne]
Ce qu'on veut voir : [ex: chien qui prend son complément, owner qui montre la boîte]
Ce qu'on ne veut pas : [ex: pas de mise en scène trop pro, pas de discours médical]
Allégations autorisées : voir `04-legal/allegations.md`
Format : [Reel 15-30s / Story / Photo]
Deadline : [Date]
