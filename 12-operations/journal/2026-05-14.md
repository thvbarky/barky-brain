## 💡 Insights techniques

### Champ `Visual` Notion DB Barky Creatives = string URL simple, pas array JSON
**Découverte 14/05/2026 PM.** Le champ `Visual` (type "file" Notion, SQLite comment `JSON array of zero or more file IDs`) **accepte simplement une string URL** quand on passe par `notion-update-page` MCP. Le format `[{"name": "x.png", "url": "..."}]` (Notion API natif external file) **renvoie** `data.startsWith is not a function`. À utiliser : `"Visual": "https://cdn.shopify.com/.../file.png?v=..."`. C'est l'expanded format implicite du MCP, jamais documenté dans la fiche tool.

→ **Implication skill `/barky-creas-batch` Étape 9** : aligner le format de push (vérifier le code actuel — la doc dit "URL CDN Higgsfield (rawUrl)" mais ne précise pas si c'est une string ou un array. Si c'est une string, on est bons. Si c'est un array, ça doit déjà avoir foiré sur les batches précédents).

### Bug import Python : code top-level d'un script importé s'exécute (14/05/2026 PM)
**Erreur faite.** J'ai écrit un mini-script `scripts/upload_creas_manuelles.py` qui importait `upload, REPO` depuis `scripts/shopify_upload_assets.py`. Au moment de l'import, le **code top-level** du script principal s'est exécuté → 24 assets ré-uploadés en doublon sur Shopify Files (nouveaux UUID pour SVG/woff2, nouveaux `?v=` timestamp pour PNGs). Le mapping `06-store/landing-pages/_shopify-asset-map.json` a aussi été écrasé.

**Correctifs appliqués** :
- Mapping restauré via `git checkout`
- `scripts/shopify_upload_assets.py` wrappé sous `if __name__ == "__main__":` pour que l'import seul soit no-op
- Doublons sur Shopify Files Admin (24 fichiers) restent là — anciennes URLs LP toujours valides, pas urgent à nettoyer. Si Thomas veut purger : `Admin Shopify > Content > Files > filtrer par date 14/05` et supprimer les copies dont l'UUID/timestamp est ≥ `1778763551`.

**Leçon générale** : tout script Python avec un main exécutable doit avoir son code sous `if __name__ == "__main__":`. À auditer sur les autres scripts du repo (`shopify_deploy_landing.py`, `shopify_seo_landing.py`, `create_landing_template.py`).
