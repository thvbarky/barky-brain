## 💡 Insights techniques (à retenir)

### Shopify
1. **Le Dev Dashboard (`dev.shopify.com`) a remplacé la création de Custom Apps via admin merchant** depuis avril 2026 (Winter '26 Edition). L'ancienne page `/admin/store/.../settings/apps/development` redirige vers Dev Dashboard.
2. **`shopify auth login` peut échouer** avec "OAuth callback store does not match the requested store" si l'utilisateur a plusieurs sessions navigateur Shopify ou si le shop demandé n'est pas accessible sous le compte connecté. Workaround : **Custom App + token Admin API** depuis le Dev Dashboard.
3. **Pour les Pages Shopify, les SEO fields sont des metafields** (`global.title_tag` + `global.description_tag`), PAS un champ direct `seo` comme pour les Products/Collections. Sinon `Field 'seo' doesn't exist on type 'Page'`.
4. **Les `@font-face` sont sanitizés** dans le `body` des pages Shopify — il faut les mettre dans le `<head>` du template Liquid pour qu'ils survivent.
5. **Le cache CDN Shopify Pages prend 1-5 min** à propager les changements (template + page content). Cache-bust avec `?bust=xxx` query param dans les tests.
6. **Le `myshopifyDomain` (interne API) peut être différent du `primaryDomain`** (alias public choisi par le merchant). Ex Barky : interne = `wcrkik-yd.myshopify.com`, public = `barky-8363.myshopify.com`.
7. **Modifier le thème actif via API requiert `write_themes`** — pour les apps tierces officielles, ça demande même une exemption Shopify, mais pour les Custom Apps internes c'est autorisé direct.
8. **Le flow `stagedUploadsCreate` + POST S3 + `fileCreate`** est le pattern officiel pour upload sur Shopify Files. `fileStatus` est `UPLOADED` immédiatement, puis `READY` après traitement asynchrone.

### Landing page / Front-end
1. **Format Bundler de Claude Design** = HTML autoportant avec 13 assets (1 SVG + 12 woff2) embedded en base64+gzip, décompressés au runtime via `__bundler/manifest` script tag.
2. **Le sanitizer Shopify** retire les `<style>` qui contiennent des `@font-face` mais préserve les autres styles. Solution : mettre les @font-face dans le `<head>` du template Liquid (zone non-sanitizée).
3. **Cache-bust `?bust=$(uuidgen)`** marche systématiquement pour tester l'effet d'une modif sur Shopify.

### Photos
1. **Les images générées par Gemini contiennent un watermark étoile** en bas à droite — à cropper ou éditer avant usage en prod.
2. **Les annotations Canva manuscrites (scribbles noirs)** ne se retirent qu'à l'édition (Photopea / Photoshop).
