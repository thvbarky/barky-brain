## 💡 Insights techniques

- **Notion Visual field accepte les URLs externes** en string direct (validé via 22 imports legacy + 5 retouches v2 + 1 thumbnail vidéo). Plus simple que d'uploader des file_ids internes. Format : `"Visual": "https://cdn.shopify.com/..."`.
- **Notion search ne supporte pas de filtre Status** — c'est une recherche text uniquement. Pour distinguer cartes par statut, il faut fetcher chaque page (lent) ou demander à l'utilisateur. Pour l'instant on demande à Thomas.
- **Notion API ne permet pas d'archiver une page via le wrapper MCP** (pas de champ `archived: true` exposé). Pour cleaner les doublons, demander à l'utilisateur de filtrer + supprimer manuellement via UI Notion.
- **Recharge selling plans matchés par nom dans le snippet Liquid weight-selector** → si Thomas renomme les selling plans dans Recharge admin (passage anglais → français), le mapping casse silencieusement et tous les `selling_plan_id` deviennent vides → add-to-cart abo plante avec "Erreur ajout panier". Fix : élargir le match Liquid à `if group.name contains 'mensuel' or group.name contains '1 month'` (idem bimestriel/trimestriel).
- **LANCEMENT10 sur abonnement** : par défaut Shopify `discountCodeBasic` n'applique pas aux selling plan items. Configurer explicitement `customerGets.appliesOnSubscription: true` + `recurringCycleLimit: 1` (s'applique sur la 1re box uniquement). Sinon Shopify affiche "Ce code n'est pas valide pour les articles de votre panier".
- **Cookie discount via /discount/CODE** est la seule méthode fiable pour appliquer auto un code promo. Fetch silencieux en `redirect: 'manual'` NE POSE PAS le cookie (a échoué dans nos tests). Solution = navigation top-level `window.location.href = '/discount/CODE?redirect=/cart'` après add-to-cart.
- **Drawer Shrine Pro natif** intercepte les events `cart:added` et s'ouvre tout seul après add-to-cart. iCart écrase ce comportement quand activé. Pour avoir le code LANCEMENT10 ET le drawer, faut un compromis : on choisit drawer iCart (mieux design) + redirect minimal pour poser cookie.
- **Shopify themePublish bloqué via MCP** par sécurité (`destructive` category). Doit être fait manuellement dans l'admin.
- **Higgsfield `gpt_image_2` génère en `1k` par défaut**, pas `2k`. Pour les textes nets sur Typo Forte, préciser explicitement `resolution: "2k"` dans les params. À ajouter dans le SKILL `/barky-creas-batch`.
- **Vidéo Meta-compatible** : H.264 + AAC, 9:16 (1080×1920) ou 1:1 (1080×1080), ≤60s pour ads in-feed. La Vidéo 1 de Thomas (46s, 9:16) est OK telle quelle, pas besoin de trim.

- **Insight stratégique critique du swipe file 2026-06-02** : le « multivitamine global daily » ne scale pas comme angle d'acquisition. Preuves cumulées :
  - Besti 8-en-1 (leur multivitamine) = **6 455 reach** vs Démangeaisons = **232 776 reach** (×35)

  - Tous les concurrents qui scalent (Besti, Balto, Wuffes, DiH) attaquent par symptôme précis
- **Conséquence pour Barky** : le « multivitamine global » reste **territoire de marque** (différenciation, page produit, owned positioning) — c'est notre gap FR à garder. Mais les **ads d'acquisition** doivent **attaquer par un symptôme précis** pour scaler. Symptôme #1 marché FR = démangeaisons / peau / pelage. #2 = articulations / mobilité chien senior. Donc on ne fait PAS "Barky, le multivitamine complet" en hook → on fait "Votre chien se gratte sans arrêt ?" → la formule complète répond à ça **+ au reste**. Le global devient l'argument de page/offre, pas le hook.
- **Compliance DGCCRF zone rouge vs verte** (formalisée via swipe file §⚠️) :
  - 🔴 Bannis : "soigne / traite / guérit", "arthrose" (Besti l'écrit, risque élevé), "régénère", "clinically-proven" santé chiffrée, garantie liée à résultat santé ("Better joints in 90 days or money back" Wuffes)
  - 🟢 OK : "soutient / contribue / favorise / aide à maintenir", "formulé avec/par des vétérinaires" (si vrai), ingrédients nommés + rôle nutritionnel, preuve sociale, "Marque française", "Satisfait ou remboursé" (argument commercial, non rattaché santé)
  - 🟠 Nuance : "soulager" borderline — OK sur bien-être/confort général, risqué si rattaché à douleur/pathologie nommée.
