## 💡 Insights techniques

- **CSS grid → flex pour le grid bundles** : avec des éléments `display: none`, un grid à 3 colonnes laisse des colonnes vides. Switch en `display: flex; justify-content: center` + `flex: 1 1 0` + `max-width: 220px` → s'adapte automatiquement à 1 / 2 / 3 bundles affichés tout en restant centré et lisible.
- **Filtrage côté JS** : `data-unavailable="true"` attribut + CSS `[data-unavailable="true"] { display: none }`. Permet de re-réafficher si on change de poids.
- **Logique de fallback du bundle sélectionné** : si le bundle actuel devient indisponible après changement de poids, on bascule automatiquement sur le bundle recommandé.
