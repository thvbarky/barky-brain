# Plan de validation lean — 6 semaines

> **Source de vérité :** [`BARKY_CERVEAU.md`](../BARKY_CERVEAU.md) §13. Ce fichier en est l'extrait opérationnel.

---

## Principe fondamental

> **Vendre avant de produire. Dépenser dans l'ordre inverse du risque.**

Organique gratuit → concept test → paid Meta → pré-commandes payantes → commande production.

---

## Budget total : **260-400 €**

| Poste | Budget |
|---|---|
| Landing page (Carrd pro si besoin) | 0-19 € |
| Meta Ads (10 €/j × 20-25 jours) | 200-250 € |
| Visuels / mockup packaging (Canva Pro) | 0-15 € |
| Domaine barky.fr (OVH) | 10-15 € |
| Micro-influenceur chien (1 story) | 50-100 € |
| **TOTAL** | **260-400 €** |

---

## Calendrier détaillé

### Semaine 1-2 — Landing + organique (0-30 €, 3 h)

- [ ] Page Barky sur **Carrd / Notion / Framer** (gratuit)
- [ ] Logo, proposition de valeur, 4 bénéfices, bouton *"Je veux être notifié au lancement"*
- [ ] Formulaire **Tally** ou Google Form connecté
- [ ] **Pas de prix, pas de produit** — juste le concept
- [ ] Bio TikTok configurée

### Semaine 2-3 — TikTok organique "build in public" (0 €, 2 h/sem)

- [ ] Format : ton visage, ton histoire
- [ ] **3 posts/semaine**
- [ ] Narratif : étudiant Dauphine qui lance une startup petfood

**Sujets à tester** :
- *"Pourquoi j'ai quitté Dauphine pour les friandises"*
- *"Est-ce que vous donnez des compléments à votre chien ?"*
- *"Les vraies différences entre une friandise classique et une friandise fonctionnelle"*

- [ ] Questions à l'audience → engagement
- [ ] **Objectif : 1 vidéo > 5 000 vues**
- [ ] Lien bio → landing page

### Semaine 3-5 — Meta Ads test (200-300 €, 2 h setup)

- [ ] **2 adsets × 2 visuels × 2 messages**
- [ ] Ciblage : propriétaires chiens 25-45 ans, France

**Tester 3 angles bénéfice simultanément** :
1. Articulations
2. Pelage / démangeaisons
3. Stress / anxiété

- [ ] Objectif conversion : inscription waitlist
- [ ] **CPL cible < 3 €**

> **Bonne nouvelle** : ce test donne **deux infos pour le prix d'une** — demande globale + problème qui attire le plus.

### Semaine 5-6 — Pré-commande (0-50 €)

- [ ] Bouton *"Pré-commander"* sur landing
- [ ] **Option A** : Stripe (vraie CB) — transparence obligatoire sur délai (*"livraison estimée dans X semaines"*)
- [ ] **Option B** : intention d'achat (bouton sans paiement) — suffisant pour un signal

---

## Critères GO / NO-GO

### ✅ GO — commander le private label

- [x] Inscrits waitlist **> 150**
- [x] CPL Meta Ads **< 3 €**
- [x] Taux clic bouton pré-commande **> 8%**
- [x] **Pré-commandes effectives > 20**
- [x] 1 vidéo TikTok **> 5 000 vues**

### ❌ NO-GO — pivoter ou attendre

- [ ] Inscrits < 50
- [ ] CPL > 8 €
- [ ] Taux clic < 2%
- [ ] Pré-commandes < 5
- [ ] Aucun engagement TikTok (< 500 vues moyenne)

→ Si NO-GO : voir [`14-knowledge/plan-b-felis.md`](../14-knowledge/plan-b-felis.md) pour le pivot compléments chat.

---

## Sources de vérité (par ordre décroissant de fiabilité)

1. **🥇 Pré-commandes payantes** (CB Stripe, pas juste email) — **métrique de vérité**
2. **🥈 Clics sur bouton "Pré-commander"** — signal intermédiaire
3. **🥉 Email waitlist** — soft intent, gratuit donc **menteur**

---

## Alertes conceptuelles

- Un CPL de 8-12 € **ne veut pas dire que le marché ne veut pas** — ça peut juste dire que ce format est plus dur à valider. Un CPL de 4-6 € serait un **signal très fort** dans ce cas.
- Toujours **tester plusieurs angles** dans les ads — ça donne demande globale + problème qui attire le plus.
- **L'email est gratuit, donc menteur.** Le vrai test est la CB.
