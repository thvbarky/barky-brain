# Barky Brain

Second cerveau de Barky — tout ce que l'IA co-CEO doit savoir pour opérer le business.

---

## Structure

```
01-identite/     → Qui on est : Thomas, la marque, le tone of voice, l'équipe
02-marche/       → Le marché : ICP, concurrents, tendances, opportunités
03-produit/      → Le produit : fiche, pricing, sourcing, packaging
04-legal/        → Compliance : réglementation, allégations autorisées, entité
05-supply-chain/ → Logistique : stock, fournisseurs, 3PL, qualité
06-store/        → Shopify : config, apps, conversion, upsells
07-content/      → Contenu : stratégie, Instagram, TikTok, UGC, lancement
08-ads/          → Publicité : Meta, TikTok Ads, créatifs, audiences
09-email-sms/    → Klaviyo : flows, séquences, bonnes pratiques
10-retention/    → Rétention : loyalty, éducation client, unboxing
11-analytics/    → KPIs, finances, weekly reviews
12-operations/   → Décisions, tasks, roadmap
13-distribution/ → Amazon, retail, affiliation (futur)
14-knowledge/    → Ressources e-com, marketing, IA
15-machines/     → Agents automatisés (à développer avec Claude Code)
```

---

## Comment utiliser ce cerveau

**Avec Claude Code :** Ouvrir ce repo dans Claude Code. Il lit CLAUDE.md et a accès à tout le contexte.

**Avec Claude.ai :** Ouvrir le projet Claude dédié Barky (paramétré avec ce contexte).

**Règle d'or :** Tout ce qu'on apprend sur le business, le marché ou les clients doit être ajouté ici. Le cerveau grandit avec le business.
