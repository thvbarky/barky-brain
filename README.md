## Le projet en une ligne

**Barky** — Marque française de friandises fonctionnelles pour chiens en abonnement mensuel DTC. Une bouchée par jour. Formulée avec un comité vétérinaire. Fabriquée en France.

Tagline : *"Nourri comme il le mérite."*

## Comment utiliser ce cerveau

### Avec Claude Code
Ouvrir ce repo dans Claude Code. Il lit `CLAUDE.md` qui importe automatiquement `BARKY_CERVEAU.md`. Tu as tout le contexte sans rien faire.

### Avec Claude.ai
Ouvrir le projet Claude dédié Barky (paramétré avec ce contexte).

### Règle d'or
Tout ce qu'on apprend sur le business, le marché ou les clients **doit être ajouté ici**. Le cerveau grandit avec le business. Le master `BARKY_CERVEAU.md` est mis à jour à chaque décision majeure.
